Seuil Final Appliqué

{{ formatPercent(modelResult?.thresholds?.final || 0) }}

C'est ce seuil qui a été utilisé pour calculer la matrice de confusion et les métriques de performance finales affichées.

Comment choisir le seuil ?

Seuil bas (0.2 - 0.4)

Détecte plus de fraudes (rappel élevé) mais génère plus de faux positifs. Idéal pour l'investigation manuelle.

Seuil moyen (0.4 - 0.6)

Bon équilibre entre rappel et précision. Recommandé pour un usage général.

Seuil élevé (0.6 - 0.8)

Haute précision, peu de faux positifs. Idéal pour les alertes automatiques avec action immédiate.

Seuil très élevé (>0.8)

Détecte uniquement les cas presque certains. Peu de fraudes détectées mais très fiable.
